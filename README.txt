Repository: https://github.com/bikram-90/bikram-weds-itishree
Target branch: main
Expected URL: https://bikram-90.github.io/bikram-weds-itishree/

UPLOAD INSTRUCTIONS
1. Extract this ZIP on your computer.
2. Open the repository on GitHub and select the main branch.
3. Choose Add file > Upload files.
4. Upload the CONTENTS of the extracted folder (not the enclosing folder).
   index.html and .nojekyll must be at the repository root, with assets/ beside them.
5. Commit directly to main (or create a pull request if you prefer).
6. In Settings > Pages, verify: Deploy from a branch > main > /(root).
7. Open Actions and wait for the Pages deployment workflow to complete successfully.
8. Visit the expected URL above and test it on mobile and desktop.

PACKAGE CONTENTS
- index.html: website entry page
- .nojekyll: prevents GitHub Pages Jekyll processing
- assets/: local images, illustrations, logo and favicon

IMPORTANT
- Preserve the assets/ folder name and its internal structure.
- Do not upload the ZIP itself to the repository. Extract it first.
- Existing files with matching names will be replaced by the uploaded versions.
- Do not delete other assets unless you have confirmed the page no longer uses them.
