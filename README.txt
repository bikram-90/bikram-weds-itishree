Bikram & Itishree Wedding Website — GitHub Pages deployment

Upload the CONTENTS of this folder to the ROOT of the repository:
https://github.com/bikram-90/bikram-weds-itishree

Required root files:
- index.html
- .nojekyll
- assets/ (keep this folder and its contents together)

Then configure Settings > Pages > Deploy from a branch > main > /(root) > Save.
Expected site URL:
https://bikram-90.github.io/bikram-weds-itishree/
